# Manual do Hikvision Driver

Manual de instalação, configuração e operação do driver de integração entre
controladoras de acesso Hikvision (linha DS-K, via ISAPI) e as plataformas
Senior X e Senior XT.

**📖 [Ler o manual](https://rdmss.github.io/md-hikvision-manual/)**

Versão do driver documentada: **2.2.1**

---

Este repositório contém **apenas a documentação**. O código-fonte do driver é
privado.

## Rodar localmente

```bash
pip install -r requirements.txt
mkdocs serve
```
